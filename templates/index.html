        Privacy & known limitations What happens to what you type, and what this model cannot do

        What happens to what you type

        • What is submitted: the five numeric values and your reflection text, to this app's own /predict endpoint.
        • Storage: none. Values are read into memory to compute a result and then discarded. This app has no database and writes no submissions to disk.
        • Logging: your reflection text is never written to console or application logs. Error logs record only the error type and the route.
        • Third parties: nothing is sent anywhere. There is no analytics, tracking, or external API call in this project.
        • Retention: nothing to retain. Close the tab and it is gone.

        Read the code and check for yourself: validation lives in validation.py, the model is loaded from models/, and nothing writes your input anywhere.

        Known limitations

        • The training data is synthetic — generated by a random script, not collected from students.
        • Held-out accuracy on that synthetic data is roughly 63%. The model is wrong about one classification in three.
        • The numeric branch scores 96% on the rows it trained on but 63% on held-out rows. A large share of the training score was memorisation, not skill.
        • It has never been validated against real mental-health outcomes, and no such validation exists for it.
        • The text branch is keyword-based pattern matching, not comprehension. It does not understand what you wrote.
        • It cannot detect self-harm, crisis, or any clinical condition, and it must not be used to try.

        Educational ML demonstration. Not a medical device, not a diagnostic tool, and not a substitute for professional care.
