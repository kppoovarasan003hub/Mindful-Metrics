# Model Card: MindfulMetrics Hybrid Classifier

## 1. Model Details

- **Model Name:** MindfulMetrics Hybrid Student Wellbeing Classifier
- **Model Type:** Hybrid Ensemble (RandomForest + TF-IDF Logistic Regression)
- **Version:** 1.0.0
- **Developers / Maintainers:** Educational Demonstration
- **Date Trained:** 2026-10-04
- **License:** Educational / Demonstration Use Only

### Architecture Overview

MindfulMetrics blends two independent branches using a fixed linear combination:
- **Numeric Branch (70% weight):** `RandomForestClassifier` trained on 5 numeric features (`marks`, `attendance`, `sleep_hours`, `screen_time`, `assignment_delay`).
- **Text Branch (30% weight):** `TfidfVectorizer` (sparse matrix representation, sublinear TF scaling, max 1000 features, English stop words) followed by `LogisticRegression` (multinomial, balanced class weights).
- **Ensemble Combination:**
  $$\hat{P}(\text{risk} = c) = 0.7 \times P_{\text{numeric}}(c) + 0.3 \times P_{\text{text}}(c)$$
- **Output Labels:** `LOW` (0), `MEDIUM` (1), `HIGH` (2).

---

## 2. Intended Use & Target Users

- **Intended Use:** Demonstration of an end-to-end, responsible ML pipeline: synthetic data generation, train/test isolation, held-out evaluation, local explainability via per-prediction feature perturbation, and strict server-side validation.
- **Out-of-Scope / Prohibited Uses:**
  - **Clinical diagnosis or mental health screening:** The model is not trained on clinical data and has no clinical validity.
  - **Automated academic disciplinary actions or interventions.**
  - **Crisis detection:** The model cannot recognize acute distress, suicidal ideation, or self-harm risks.

> ⚠️ **CRITICAL DISCLAIMER:**  
> This model is strictly an educational prototype. Its held-out accuracy is approximately **63%**, meaning it is incorrect in roughly 1 out of 3 evaluations. Do not use this model or its predictions to make decisions regarding any real person.

---

## 3. Training & Evaluation Data

- **Dataset Origin:** 100% Synthetic, procedurally generated by `training/make_dataset.py` with seed `20240917`.
- **Dataset Size:** 1,200 rows total (960 train / 240 held-out test).
- **Split Strategy:** Stratified 80/20 train/test split with `random_state=42`.
- **Deliberate Noise:** An 8% label noise rate and synthetic phrase randomness were injected so the model cannot trivially memorise the generator without real generalization challenges.

---

## 4. Evaluation Metrics (Held-Out Test Set)

The vectorizer, random forest, and logistic regression models were fitted solely on the training split ($N=960$). The metrics below represent performance strictly on the unobserved held-out split ($N=240$).

| Branch / Model | Held-out Accuracy | Macro Precision | Macro Recall | Macro F1 |
|---|---|---|---|---|
| **Numeric Branch** (Random Forest) | 62.50% | 0.6406 | 0.6255 | 0.6289 |
| **Text Branch** (TF-IDF + LR) | 58.75% | 0.5739 | 0.5859 | 0.5774 |
| **Hybrid Blend** (0.7 / 0.3) | **63.33%** | **0.6359** | **0.6333** | **0.6329** |

### Training vs. Test Disparity (Overfitting Notice)
- **Numeric Branch on Training Data:** 96.04% accuracy.
- **Numeric Branch on Held-Out Test Data:** 62.50% accuracy.
- *Insight:* High training accuracy is an artifact of memorization on synthetic tree splits; only held-out metrics reflect realistic generalization.

## 5. Explainability & Serving

- **Explainability:** Per-prediction perturbation. Rather than displaying static global importance, the system recalculates probability deltas when perturbing inputs around the user's specific submission.
- **Branch Transparency:** The UI explicitly displays the Numeric score, Text score, and Blended score side by side to indicate when the two modalities disagree.
- **Privacy & Security:**
  - Input reflection text is processed in-memory and immediately discarded.
  - No database or file storage of submissions.
  - Strict input validation prevents NaNs, infinities, out-of-range numbers, and empty feedback.
